# The Séance Times — фирменный стиль

Навык для агента: любой текст, вёрстка или картинка для газеты делается по этой системе. Источник правды — `assets/site.css`, `tools/render.py`, `rules/EDITORIAL.md`; здесь — сжатая выжимка.

## Палитра (только эти цвета)

```
paper      #f4f0e5   фон
paper-2    #efe9da   врезки, полосы
ink        #181410   текст, линейки
ink-soft   #3a332a   подзаголовки, лид
muted      #5e5546   подписи, даты, источники
accent     #8a1b1b   единственный акцент
accent-soft #a8453f  ховер акцента
hair       rgba(24,20,16,.28)  тонкие разделители
```

Один акцент на экран. Без градиентов, теней, размытий, скруглений больше 2px.

## Шрифты

- Заголовки — `Playfair Display`, Iowan Old Style, Palatino, Georgia, serif. Заголовок номера `clamp(2.15rem, 8.6vw, 5.9rem)`, `letter-spacing .02em`.
- Текст — `Lora`, Iowan Old Style, Georgia, serif, 17.5–18px, `line-height 1.62`.
- Служебное (рубрики, даты, источники) — `Segoe UI`, system-ui, Helvetica, Arial, sans-serif, .68–.7rem, uppercase, `letter-spacing .14–.2em`.

Мера строки — `--measure: 34rem` (≈68 знаков). Длиннее — ошибка.

## Голос

Живой русский с иронией и деталью. Конкретика вместо восторга: цифры, даты, цены, имена. Факт из первоисточника отдельно, редакционный вывод отдельно. Короткие абзацы, одна мысль — один абзац. Честная оценка рисков.

Запрещено: «революционный», «прорывной», «в современном мире», «не секрет, что», «контент», «экосистема», канцелярит, рекламный восторг, эмодзи.

## Рубрики

БЫЛИЧКИ (фольклор) · СЕАНС (спиритизм, полтергейст) · ЧУДЕСА (святые, явления) · НЕБО (НЛО, похищения) · КОНСПИРОЛОГИЯ · АРХИВ (книги) · ЛАБОРАТОРИЯ (наука) · ШУМ (дарк-фолк, блэк-метал).

Не берём: политику и новости РФ, криминал, ДТП, спорт, шоу-бизнес, ИИ-модели и цены API, рынки, крипту, бытовые советы.

## Вёрстка

- Собирается скриптом: `python tools/render.py issue.json` → `issues/<дата>.html`. HTML руками не править.
- Вертикальный ритм — линии-волоски 1px, не пустоты.
- Шапка: «THE» отдельной строкой, `letter-spacing .5em`, `text-indent .5em`.
- Полоса выпуска — uppercase sans, по левому краю текста.

## Изображения

Только свободные (Wikimedia Commons, NASA), локально в `assets/img/`, JPEG, ширина ≤1600px. Исходники — в `assets/_src/` (не публикуется). Подпись и источник обязательны.

## Проверка перед сдачей

```
python tools/typo.py issues/ДАТА.html
python tools/publish.py build
python tools/publish.py check
```

`check` без ошибок — иначе номер не готов.
